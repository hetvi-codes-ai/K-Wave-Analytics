#  K-Wave Analytics
### AI-Powered K-Pop Trend Intelligence Platform

K-Wave Analytics is a machine learning-based music analytics platform designed to explore K-pop music trends and predict song performance using historical music data.

The platform combines data analysis, machine learning, and interactive visualizations to provide insights into song popularity, artist performance, trending patterns, and potential Top 10 songs.

##  Key Features

- **Music Analytics:** Analyse K-pop songs, artists, popularity, and monthly music trends.
- **AI Predictions:** Predict song popularity, trending status, Top 10 potential, and artist success scores.
- **Artist Analysis:** Explore artist performance and popularity statistics.
- **Song Recommendations:** Discover recommended songs based on artist selection and popularity.
- **AI Insights:** Convert prediction results into simple, understandable explanations.
- **Data Export:** Download prediction reports in CSV format.

##  Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Plotly
- Pickle
- CSV Dataset

##  Machine Learning Models

- Random Forest Regressor
- Random Forest Classifier

##  Project Objective

The objective of K-Wave Analytics is to combine music data analysis and machine learning to understand K-pop music patterns and generate meaningful predictions through a user-friendly dashboard.
